Help the user create a detailed feature specification following our constitution principles.

**Process:**

1. **Ask the user about the feature:**
   - What is the feature name?
   - What problem does it solve?
   - Who are the users?

2. **Create a specification file:**
   - Create `.specify/specifications/[feature-name].md`
   - Use the template from `.specify/MANUAL-WORKFLOW.md`
   - Include:
     * User Story (As a... I want... So that...)
     * Requirements (Must Have, Should Have, Could Have)
     * Acceptance Criteria
     * Success Metrics
     * Constitution Alignment (check all 10 principles)
     * Risks & Mitigations

3. **Review against constitution:**
   - Verify it aligns with Zero Manual Intervention
   - Verify it follows Safety First
   - Verify it includes Comprehensive Logging
   - Verify it's Cost-Effective
   - Verify it maintains Quality
   - Check all 10 principles from `.specify/constitution.md`

4. **Save the specification:**
   - Write the file to `.specify/specifications/[feature-name].md`
   - Display the specification for user review
   - Ask if they want to proceed to planning phase

**Constitution Principles to Check:**
Read `.specify/constitution.md` and ensure the feature aligns with all 10 core principles.
