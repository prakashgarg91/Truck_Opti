# Evidence Format

Use this format in `DISCUSSION.md`, task completions, launch checks, and release notes.

## Minimum Evidence Block

```md
Files changed:
- path/to/file

Commands run:
- `command here`

Results:
- PASS/FAIL summary with the key output

Risks / follow-up:
- remaining issue or `none`
```

## Launch Evidence

Launch-related evidence should also include:

- checklist phase or gate
- owner-only action if any
- whether the result is verified, skipped, or blocked
