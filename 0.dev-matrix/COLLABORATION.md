# Truck_Opti Collaboration Protocol

## Shared Runtime

- `STATE.md` tracks active agents and live issues
- `TASK.md` tracks ownership and completion
- `DISCUSSION.md` captures handoffs and judge notes

## Working Rules

1. read `TESTING_PRINCIPLES.md` before coding
2. read `SECURITY.md` before auth, data, or payment work
3. make small changes with validation after each slice
4. write owner-only tasks clearly when they block launch
